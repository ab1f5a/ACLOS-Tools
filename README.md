**ACLOS Tools** 是一款专为国服无畏契约启动器设计的工具箱，集成了启动器安装、更新拦截、配音修改的功能。

---

## ✨ 核心特性

* **免安装单文件**：不用装 Python 环境，点开直接用。
* **全 GUI 操作**：采用图形化界面，告别难看的命令行。
* **毫秒级实时拦截**：基于内核级文件系统监听，在更新请求生成的瞬间完成配置注入。
* **智能权限锁定**：自动把文件改回只读属性，防止启动器在运行中偷偷修复或强制升级。
* **自适应路径搜索**：内置全盘扫描，也支持手动选文件，确保精准定位启动器。
* **一站式工具箱**：内置老版本启动器安装功能，单文件完成所有操作。

---

## 🚀 使用指南

### 1. 下载工具
前往本仓库的 [Releases](../../releases) 页面，下载最新的 `ACLOS_Tools_x86.exe`。
[点击这里](https://down.val.qq.com/aclos/release/2.13.1.393/VALORANT_CN_installer_v2.13.1.393.exe) 下载 2.13.1 版本启动器安装包。**（非必须）**

### 2. 操作步骤
1. 以**管理员身份**运行 `ACLOS_Tools_x86.exe`。如果打开后提示没权限，记得右键选择“以管理员身份运行”。
2. 在 ACLOS Tools 界面里执行操作。
3. 以后直接用桌面上新建的快捷方式启动游戏。
4. Enjoy it~
